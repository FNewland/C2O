# Figure QA — visual review of all textbook figures

Scope: the 29 `docs/assets/figures/fig_*.png` files and the 11 rasterised inline SVGs in `docs/assets/figures/_inline/svg_*.png`. Every image was opened and inspected; every flagged figure's generator (`fig_<name>.py`) and `uottawa_brand.py` were read.

Defect codes: **a** text clipped / outside axes · **b** overlapping text/labels/legend · **c** labels overflowing boxes/cells · **d** illegible / low contrast / indistinguishable colours · **e** "SpaceCDF · uOttawa SEDTI" watermark present · **f** course-specific wording · **g** factual / engineering issue.

Verdict counts (fig_*.png): **OK 4 · minor fix 14 · regenerate 11**. Inline SVGs: OK 2 · minor 6 · regenerate 3.

Note: **every** `fig_*.png` has the watermark (e) because every script calls `add_footer(fig)`; it is listed once here and not repeated per row. Every script also hard-codes `fig.savefig("/sessions/serene-eager-noether/mnt/docs/assets/figures/…")`, a path that does not exist on this machine — none of them can be re-run as-is (see common fixes).

## Common fixes for all scripts

1. **Watermark.** Remove `add_footer(fig)` from all 29 scripts (and delete `add_footer` from the brand module, or make it a no-op). The OER is CC BY; attribution belongs in the caption/colophon, not burnt into each image.
2. **Output path.** Replace every `fig.savefig("/sessions/serene-eager-noether/mnt/docs/assets/figures/fig_x.png")` with
   ```python
   from pathlib import Path
   OUT = Path(__file__).resolve().parent
   fig.savefig(OUT / "fig_x.png")
   ```
   (or `OUT / (Path(__file__).stem + ".png")`). None of the scripts can currently run on the checkout.
3. **Neutral style module.** Rename `uottawa_brand.py` → `figure_style.py` (keep `apply_style`, `COLORS`, `SERIES`), update the docstring ("Shared style for textbook figures"), and change the 29 imports. Keep the palette but add two distinguishable accents (amber `#c8963e`, violet `#5b3a7e`) to `COLORS`/`SERIES` — the current eight entries contain three near-identical pairs (garnet/garnet_2, blue/blue_2, green/green_2) and `polar` (#f2f2f2) is used as a *line* colour in five scripts (fspl, gsd, signal_noise, tsiolkovsky, system_v, pass_geometry), where it is invisible.
4. **dpi.** `savefig.dpi = 200` is fine for print; keep it, but set `figure.dpi = 100` and fix each `figsize` to the column width actually used (≈ 6.5 in for the PDF body) so font sizes come out as designed instead of being scaled.
5. **`bbox_inches="tight"`.** `savefig.bbox = "tight"` in `apply_style()` is what let off-axes text (thermal_balance, data_volume, trl, antenna suptitle) silently grow the canvas. Either (a) keep "tight" but add `clip_on=True` / `annotation_clip=True` to every `ax.text`/`ax.annotate` placed in data coordinates, and never place labels outside `xlim/ylim`; or (b) set `savefig.bbox = None` and use `fig.tight_layout()` / `constrained_layout=True` so overflow becomes visible as clipping during QA instead of being hidden by canvas growth.
6. **Legend placement.** Six figures have legends over data (hohmann, signal_noise, orbital_lifetime, beta_eclipse, gsd borderline, power_modes). Prefer `loc="best"` only for sparse plots; otherwise place legends below the axes (`bbox_to_anchor=(0.5, -0.18), loc="upper center", ncol=3`).
7. **Course wording.** `fig_trl.py` (two strings, docstring) and `fig_kepler_proof.py` ("EOSAT-1") carry course/mission names; `fig_canadian_sector.py` lists "uOttawa SEDTI" as a lab. Grep for `Course|Day \d|CDF|EOSAT|SEDTI` after the edits.
8. **Re-rasterise inline SVGs** after editing the markdown (`docs/build_pdfs_fpdf.py`), since several `_inline` PNGs are already stale relative to the chapter sources.
