# smo-link: response to the independent security review

*2026-10-29. This answers `research/LINK_REVIEW.md`, the review of smo-link v1. Every finding was fixed in protocol **v2** (package 0.2.0) unless it is listed under "Deferred". The design changes are in `LINK_DESIGN.md` §3.1–3.3, §3.6–3.8, §4 and §7.*

## Where the tests are

- **Regression tests:** `tests/test_link/test_security.py` (test names start with the finding id), plus updated `test_unit.py`, `test_component.py` and `test_e2e.py`.
- **Each test reproduces the reviewed failure.**
  - The review's repro scripts were turned into these tests: `t_tc_fin.py` → H1, `t_proxy.py` → H3, `t_e2e_bypass.py` → M1, `t_misc.py` → M2/M4/M6/L5, `t_slow.py` → M4.
  - The protocol-independent defects were checked against a saved copy of the v1 package. They all reproduced there and are gone in v2: `/config#x` allowed, NaN accepted, a trailing-`\n` dump name accepted, a 16-byte secret accepted, a non-ASCII `sig` raising `TypeError`, and TM fan-out over 8 MiB.
  - The protocol-dependent tests cannot run against v1, which has no handshake. They were checked by mutation instead: each fix was reverted in place, the matching tests were run, and they failed. The fixes reverted were:
    - RST → FIN (4 H1 tests fail);
    - v1-style supersede, `await old.close()` before bind (H1 supersede fails);
    - no tag check (3 H2 tests fail);
    - no agent route re-check (M1 agent test fails);
    - no TC deadline or degraded rule (2 M5 tests fail);
    - no pre-auth timer (M4 fails).
- **Run:** `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=packages/smo-rfsim/src:packages/smo-link/src python -m pytest -p no:cacheprovider -q tests/test_link --timeout=180`

## Deferred (with reasons)

- **Confidentiality on the LB→GSG hop.** v2 MACs frames but does not encrypt them, so TM, TC and proxied pages are readable inside the VPC. That needs TLS to the GSG (a private CA on the VM) or AEAD framing. It is documented in LINK_DESIGN §3.3 and §7 and in `deploy/gcp/README.md`.
- **TLS CA pinning in the agent** (review H2.3). With mutual challenge-response, a MITM holding a valid certificate still cannot bind or inject anything. Pinning would add certificate-rotation work for every student laptop.
- **Simulator TC 8001 on the compose network.** In the `space` and `local-demo` profiles the simulator binds 0.0.0.0 inside its container, because its single `SMO_BIND` also covers the published HTTP console. Other containers on that compose network could reach TC 8001 directly. Fixing this needs a separate HTTP bind in `smo-simulator`, outside this package's "no code change elsewhere" rule. The network contains only our own containers and nothing is published beyond host loopback.
- **Per-tab `/ws` proxying cost** (design note, not security). Synthesising `state_update` from STATE at the GSG stays future work (LINK_INTERFACES §3.2).
- **Pre-auth per-IP limits behind the GCP LB.** There the source is a Google front end, so the per-IP caps are a backstop. Per-client limiting is Cloud Armor's rule 1000 (`deploy/gcp/README.md` §4).

## Behaviour changes operators will notice

- **Upgrade both ends together.** A v1 agent or GSG is refused (401 at the header, or a protocol error).
- A **supersede** (agent reconnect) now resets TC sockets, as a link loss does. The MCS shows `No TC connection` briefly and reconnects.
- The instructor proxy serves **only** the allowlisted routes. A new sim route must be added to `httpproxy.py` (LINK_DESIGN §3.7) before it is reachable through the GSG.
- Docker ground ports are on 127.0.0.1 until `SMO_PUBLISH_ADDR` is set.
- `ws://` to a hostname needs `SMO_LINK_ALLOW_INSECURE=1`.
- Behind the LB, set `SMO_GSG_ALLOWED_ORIGINS` (or `SMO_GSG_ALLOWED_HOSTS`) to the instructor host name, or the proxy answers `403 host not allowed`.

## Re-review 2026-10-29 (new findings)

The reviewer re-ran every attack against protocol v2: H1–H4, M1–M3 and M6 verified fixed. New items:

| ID | Severity | Status | Change |
|---|---|---|---|
| N1 | MEDIUM (availability) | **Fixed** | A 401 now closes the connection and releases its pre-auth slot immediately (`force_close` + `guard.release`). When the pre-auth table is full the **oldest** unauthenticated connection is evicted instead of refusing the newcomer (`preauth.evicted` in `/api/link`). Test: `test_n1_401_frees_slot_and_cap_evicts_oldest`. Cloud Armor per-client rate limiting on `/link` stays recommended. |
| N2 | LOW (fails open) | **Fixed** | The agent's GSG-time estimate is anchored to the monotonic clock (`ClockEstimator.mono_offset`, WELCOME offset likewise), so a backward step of the laptop's wall clock can no longer make a stale TC look fresh. | N3 | LOW | Known limitation | A TC refused at the agent (expired, malformed, sim socket down) is reported as a NOTICE and counted in `/api/link`, but the MCS has no channel for it and still shows SENT.
